## Что это такое?

Это готовая торговая стратегия для платформы **TradingView**. Написана на языке **Pine Script v6** — встроенном языке TradingView.

Стратегия анализирует рынок по двум методологиям одновременно:

- **SMC (Smart Money Concepts)** — ищет зоны, где крупные участники (банки, фонды) накапливают или сбрасывают позиции
- **Wyckoff VSA** — анализирует объём торгов вместе с движением цены, чтобы понять реальную силу покупателей и продавцов

Когда оба метода дают совпадающий сигнал — стратегия открывает сделку. Это снижает количество ложных входов.

---

## Для кого это?

- Для тех, кто торгует на TradingView (форекс, крипто, акции, фьючерсы)
- Для тех, кто хочет готовый инструмент с настраиваемыми параметрами
- Для тех, кто знаком с базовыми понятиями: уровни поддержки/сопротивления, тренд, объём

> Стратегия **не** торгует сама. Она работает в режиме backtesting (проверка на истории) и показывает сигналы на графике. Открывать реальные сделки нужно вручную или через алерты.

## Как установить (пошагово)

**Шаг 1.** Зайди на [tradingview.com](https://tradingview.com) и открой любой график

**Шаг 2.** Найди внизу экрана вкладку **"Pine Editor"** и кликни на неё

**Шаг 3.** Открой файл `strategy.pine` из этого репозитория, выдели весь текст и скопируй (Ctrl+A, Ctrl+C)

**Шаг 4.** Вставь скопированный код в Pine Editor (Ctrl+A чтобы выделить старый код, затем Ctrl+V)

**Шаг 5.** Нажми кнопку **"Add to chart"** (синяя кнопка сверху справа в Pine Editor)

**Шаг 6.** Стратегия появится на графике. В нижней части экрана откроется панель с результатами бэктеста.

## Основные настройки

Все настройки открываются через шестерёнку ⚙️ рядом с названием стратегии на графике.

### Управление риском

| Параметр | Что делает |
|----------|-----------|
| Режим расчёта позиции | **Fixed Cash** — фиксированная сумма на сделку; **Risk per Trade ($)** — фиксированный риск в деньгах; **Risk % of Equity** — риск в % от депозита |
| Risk per trade, $ | Сколько денег ты готов потерять в одной сделке (например, $20) |
| Risk % of equity | То же самое, но в процентах (например, 0.5% от депозита) |

### Take Profit (цели)

| Параметр | Что делает |
|----------|-----------|
| TP Mode | **Risk/Reward** — TP кратен стопу (например, 2:1); **Liquidity Target** — TP на ближайшем уровне ликвидности; **Prioritized** — три цели TP1/TP2/TP3 |
| TP1 / TP2 / TP3 | Процент позиции, закрываемый на каждой цели |
| Move SL to BE | Перенести стоп в безубыток после достижения TP1 |

### Фильтры (что блокирует плохие сигналы)

| Фильтр | Рекомендация |
|--------|-------------|
| Фильтр по тренду | Включить, если хочешь торговать только по тренду |
| Фильтр режима рынка | Включить — блокирует торговлю в "боковике" |
| Фильтр по VWAP | Включить — отсеивает сигналы против основного баланса |
| Торговать только в Kill Zone | Включить для торговли только в активные сессии |
| Фильтр объёма | Включить — игнорирует сигналы на слабом объёме |

### Kill Zones (торговые сессии)

Стратегия знает 4 ключевые торговые сессии (по EST):

| Сессия | Время EST | Что это |
|--------|-----------|---------|
| Asia | 20:00–00:00 | Азиатская сессия — обычно тихая |
| London | 02:00–05:00 | Лондонское открытие — часто сильные движения |
| New York AM | 09:30–11:00 | Лучшее время для торговли |
| New York PM | 13:30–16:00 | Вторая активная фаза NY |

### Wyckoff модуль

| Параметр | Что означает |
|----------|-------------|
| Climax Volume Multiplier | Во сколько раз объём должен превышать среднее, чтобы считаться "экстремальным" (по умолчанию 2.0) |
| Spring Confirmation Bars | Сколько баров нужно после Spring для подтверждения (по умолчанию 3) |
| Trade Spring Setups | Торговать ложные пробои поддержки вниз |
| Trade Upthrust Setups | Торговать ложные пробои сопротивления вверх |
| Require Volume Confirm | Требовать подтверждение объёмом (рекомендуется включить) |

## Словарь терминов

| Термин | Простое объяснение |
|--------|--------------------|
| SMC | Smart Money Concepts — анализ действий крупных игроков |
| Wyckoff | Метод анализа рынка через объём и фазы накопления/распределения |
| VSA | Volume Spread Analysis — анализ объёма и размера свечи |
| FVG | Fair Value Gap — "дыра" в цене, куда цена часто возвращается |
| BOS | Break of Structure — пробой ключевого уровня структуры |
| CHOCH | Change of Character — смена характера движения (намёк на разворот) |
| BSL / SSL | Buy-Side / Sell-Side Liquidity — скопления стопов над/под уровнями |
| Spring | Ложный пробой поддержки вниз с быстрым возвратом |
| Upthrust | Ложный пробой сопротивления вверх с быстрым возвратом |
| SOS | Sign of Strength — признак силы (подтверждение роста) |
| SOW | Sign of Weakness — признак слабости (подтверждение падения) |
| HTF / LTF | Higher/Lower TimeFrame — старший/младший таймфрейм |
| VWAP | Volume Weighted Average Price — средняя цена, взвешенная по объёму |
| Kill Zone | Временной диапазон с максимальной активностью рынка |
| ATR | Average True Range — средний диапазон свечи (мера волатильности) |

## Алерты (уведомления)

Стратегия может присылать уведомления. Чтобы настроить:

1. Кликни правой кнопкой на название стратегии в списке индикаторов
2. Выбери **"Add alert"**
3. В условии выбери нужное событие

Доступные уведомления:
- Вход в Kill Zone
- Сигнал на покупку / продажу (с указанием причины)
- Достижение TP1, TP2, TP3
- Перенос стопа в безубыток
- Срабатывание Stop Loss
